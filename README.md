# Radar-Detector

Research and a build plan for a receive-only radar/laser alert system, using an iPhone app and a Bluetooth (ESP32) bridge.

- [How radar detectors work and what they detect](docs/how-radar-detectors-work.md)
- [Plan: iPhone + wireless adapter](docs/iphone-plan.md)

> Check your local laws. Radar detectors are banned in some places, and jammers are illegal almost everywhere. This project is receive-only.
